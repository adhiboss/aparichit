# Knowledge Base Sources

This file records source texts, translators, publication years, and rights/licensing information for the APARICHIT knowledge base.

## 1. Primary Source: Garuda Purana
- **Work**: The Garuda Purana (English Translation)
- **Translators / Editors**: Ernest Wood and S. V. Subrahmanyam
- **Publication Year**: 1911
- **Series**: The Sacred Books of the Hindus (Vol. 9)
- **Publisher**: The Panini Office, Bhuvaneswari Asrama, Allahabad
- **Copyright Status**: Public Domain
- **Usage Rights**: Free for all uses without copyright restrictions
- **Coverage**: Achara Kanda, Dharma Kanda, Preta Kanda

## 2. Source Ingestion Integrity Rules
1. Only public-domain and explicitly licensed translations may be ingested.
2. Every chunk must retain:
   - Source title
   - Translator/edition
   - Chapter / Adhyaya number
   - Verse / Shloka number (if available)
   - Section (e.g. Achara Kanda, Preta Kanda)
3. Never ingest modern copyrighted commentary without written authorization.
